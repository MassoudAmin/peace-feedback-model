# Source data

Download each file into this directory under the name the scripts expect. Nothing here is redistributed; each provider's terms apply.

| File expected | Source | Where |
|---|---|---|
| `OrganizedViolenceCYDataSet26_1.csv` | UCDP Organized Violence Country-Year Dataset 26.1 | ucdp.uu.se/downloads |
| `GEDEvent_v26_1.csv` | UCDP Georeferenced Event Dataset 26.1 | ucdp.uu.se/downloads |
| `UcdpPrioConflict_v26_1.csv` | UCDP/PRIO Armed Conflict Dataset 26.1 | ucdp.uu.se/downloads |
| `V-Dem-CY-Core-v16.csv` | V-Dem Country-Year Core v16 | v-dem.net |
| `SIPRI-Milex-data-1949-2025_v1_2.xlsx` | SIPRI Military Expenditure Database (sheet "Share of GDP") | sipri.org/databases/milex |
| `food_price_indices_data.csv` | FAO Food Price Index, monthly | fao.org/worldfoodsituation |
| `Inflation-data.xlsx` | World Bank Global Database of Inflation (sheet `fcpi_m`) | worldbank.org/en/research/brief/inflation-database |
| `API_FI.RES.TOTL.MO_DS2_en_csv_v2_407033.csv` | World Bank, total reserves in months of imports (FI.RES.TOTL.MO) | data.worldbank.org |
| `wfp_food_prices_global_YYYY.csv` (one per year) | WFP Global Food Prices | data.humdata.org |
| `events.YYYY.tab` or `events_YYYY.tsv` (one per year) | ICEWS event data | dataverse.harvard.edu (ICEWS) |

Version numbers in the file names are the ones used for the paper. A later release will change some counts.
